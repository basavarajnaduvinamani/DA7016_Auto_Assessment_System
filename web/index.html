DA7016 · Auto-Assessment

Grade an answer sheet against its rubric

Load an exam spec and an answer sheet, then grade. Every mark points to a rubric criterion and the student's own words, and each lost mark comes with a next step.

Offline mode · no API key connected

1 · Exam spec

Questions, max marks, rubric criteria and model answers, as YAML or JSON. The sample quiz is loaded.

2 · Answer sheet

Label answers as the student wrote them, for example "Q1", "Ans 2" or "3.". Scanned PDFs and photos need OCR, which turns on with IndicOCR or a Bodhan key.

3 · Grader

This page runs the project's offline pipeline in your browser: question segmentation, the lexical baseline grader and rubric-based feedback, ported from src/autoassess and checked to give identical marks. The LLM grader, critic, Bodhan OCR and translated feedback run in the Python app (python app.py or autoassess grade) once keys are set.
