\begin{abstract}
Auto-Assessment is an implemented pipeline for grading complete answer sheets against a teacher's rubric. It accepts typed answers, scanned documents or photographs, and produces criterion-level marks, evidence-linked feedback, an HTML report and a red-ink annotated booklet. A mark must survive a quote check against the answer text; an advocate and a critic review the award in opposite directions. Confidence signals identify answers that need teacher review. The central educational question is whether feedback is specific enough for a student to improve, rather than whether an automated score merely resembles a human score. This report describes the implementation, the evaluation protocol and the mechanisms for assembling reproducible results. Empirical results and the example marked page remain explicitly pending; the report makes no claim of measured grading accuracy, learning gains or deployment readiness.
\end{abstract}
