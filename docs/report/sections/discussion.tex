\section{Discussion and limitations}
The design makes awards inspectable, but inspection is not the same as correctness. A quote can occur in an answer while expressing a misconception. A critic can repeat the grader's mistake, and an advocate can miss a valid alternative explanation. Shared model families, prompts and training distributions can correlate these errors. Repeated runs and low disagreement therefore support a diagnostic signal, not an independent proof of a mark.

The rubric defines the scope of justified feedback. Vague, bundled or incomplete criteria can make a precise-looking output misleading. Rubric lint flags suspicious descriptions, duplicate checks, missing model answers and invalid follow-through relationships, but teachers still need to review whether the rubric represents what they intend to assess. A learner should not receive a confident correction based only on a brittle keyword match or a flawed reference answer.

Handwritten and multilingual scripts add further uncertainty. OCR may lose equations, merge lines or associate text with the wrong region. The segmenter can then assign recognisable words to an incorrect question. Page-image grading offers another input route, but its relaxed quote check changes the evidence guarantee. Comparison of text, image and hybrid conditions must state that difference explicitly. Translation may also change the meaning or specificity of a suggested correction.

The confidence rule is intentionally conservative when a warning is present, yet it can accept an error when every available signal misses the same failure. Missing OCR confidence and an unavailable second examiner reduce the information available to the rule. Future work should assess calibration and the workload cost of review, instead of interpreting the combined value as a probability that a teacher would agree.

The present report has no empirical conclusion about educational effectiveness. A small convenience sample, repeated use of development scripts or insufficient representation of a language could make apparent gains unreliable. The improvement study must distinguish better rubric alignment from durable learning, and account for the fact that students may improve simply by attempting an answer again. Any reported benefit should be limited to the tested setting and comparison conditions.
